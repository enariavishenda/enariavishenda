I'm CEO & CTO at **Metastability Inc.** with a background in **Nanophysics and Physical Electronics**. Senior software engineer and team lead specializing in full-stack development, embedded systems, distributed infrastructure, and machine learning engineering.

**Technical Expertise:** End-to-end system design from embedded hardware interfaces to web applications. I build self-hosted infrastructure, custom authentication mechanisms, real-time data processing systems, and deterministic computational algorithms. All development is done in-house with complete ownership of the technology stack.

**Core Competencies:**
- Low-level systems programming (Assembly, C/C++, Go, Rust)
- Embedded systems and hardware integration
- Full-stack web development (React, Angular, Vue, Nextjs, Node, PHP, Django, Flask)
- Distributed systems and database architecture
- Machine learning pipelines and AI systems
- Bare-metal infrastructure (Proxmox, custom networking)
- Fintech platforms and secure authentication systems
- Cross-platform application development
- Game development and graphics programming
